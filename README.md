# Graduate Tracking Web Prototype

Academic web-development prototype focused on graduate tracking and employment information.

## Features

- Personal, academic, and employment information views
- Graduate follow-up workflow
- Job-board section
- PHP pages, CSS styling, and supporting media assets

## Technologies

PHP, HTML, CSS, and local static assets.

## Running locally

Use a local PHP server or an environment such as XAMPP to run the `.php` files.

## Notes

This repository preserves the original academic project and its file organization.
